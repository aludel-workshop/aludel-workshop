# Test project rotation

These are ideas for throwaway projects used to test onboarding, GitHub creation, previews and the layers from start to finish. Pick the next one that hasn't been used under the current flow. Delete it with `node apps/portal/tools/delete-project.mjs <project-id>` when you're done.

The briefs are the owner's original onboarding text, lightly trimmed. They were saved on 2026-09-24, when the first six local-only test workspaces were deleted (PLATFORM-PIPELINE-01). Henry's Gate was left out on purpose: it had no idea behind it.

| Name | Brief |
|---|---|
| Browser Buddy | A simple website that's a window into a little pet's world. Leave it open and watch it chilling and doing its thing; interact with it and customize it if you want. Good vibes to keep in the background. |
| WheresTheBest | Rank food items (a burger, a lasagne) relative to each other across the restaurants you try. The app combines your rankings with other people's, so you can filter and find the actual best burger. |
| Mariachi Madness | Get paired with random other users to make fun music with instruments you build yourself. |
| Ranked Choice Fun! | A site that helps people understand ranked-choice voting: articles, interactive games, etc. |
| MyFeed | Tired of juggling news sites? Customize exactly what you're looking for, get a daily digest, and see what's happening on a map. |

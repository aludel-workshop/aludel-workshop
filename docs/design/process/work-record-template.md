# Work record template

Copy only applicable fields into a task record. Combine sections for small changes. Placeholders are not passing evidence.

- ID / revision / date / author:
- Outcome and observable success:
- Authorized scope and excluded effects:
- Shared structures versus project-specific choices and affected capability/handoff IDs:
- Acceptance impact: enduring product semantics, historical evidence, reopened presentation choices:
- Process weakness or existing practice being reused:
- Process improvement and how its usefulness will be evaluated:
- Work class and uncertainty rationale:
- Proposed deliverable scope (actors, stories, pages, transitions, components):

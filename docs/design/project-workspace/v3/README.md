# D-03 Work planning and history prototype

Open `index.html` through the local portal at `/reviews/project-workspace-v3/index.html`.

This is a design experiment. It tests the selected information structure, planning/history collection behavior, record details, native planning edits, and reconciliation review. It uses deterministic fixture data and browser-local draft state. It does not mutate portal records, authorize work, or represent a working migration.

The parent structure is fixed by D-02R: Product, Design, and Work; Reviews is a stage inside Work. The remaining review question is whether the proposed Work collection and reconciliation interaction make historical, planned, active, and reviewable work understandable without conflating their lifecycles.

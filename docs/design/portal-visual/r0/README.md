## Prompt contract

All three prompts requested a production-quality 1440×1024 desktop SaaS direction for Aludel, grounded in the attached v4 screenshots. They required the accepted Overview / Work / Decisions / Reviews shell, candidate identity, original intent, preview, evidence/gaps, separate accept/revise actions, and a 390px responsive inset. They prohibited new product areas, dashboards, metrics, decorative inventory, browser/device chrome and illegible microtext. The date anchor was 2026-09-19.

Direction deltas:

- **Precision Ledger:** Swiss editorial hierarchy, cool near-white canvas, graphite type, restrained cobalt accent, precise grid, fine dividers and almost no shadow.
- **Quiet Studio:** warm editorial character, parchment-white base, ink and forest text, muted terracotta attention, humanist serif headings, generous reading rhythm and minimal containment.
- **Night Signal:** dark operational workspace, navy-charcoal surfaces, warm white type, restrained mint/cyan current state, amber consequential attention, light embedded product preview, no neon or code-editor styling.

## Why this set is insufficient

The concepts show a useful mood range but do not define an upstream foundation, experience principles, token provenance, interaction-pattern contracts, component anatomy/states, accessibility behavior, maturity or change governance. Option 3 is therefore mood input to D-01F, not an accepted D-01E direction. See [R-08 research](../../../evidence/r-08-design-system-strategy.md) and the [design-system strategy](../../design-system-strategy.md).

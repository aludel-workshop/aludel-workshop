The flow must survive these states

These annotated frames specify outcomes for later interaction tests. They are not live simulations.

E1 · T1–T2 · Decision saved / Work collection

Zero, one, or several tasks

Zero: “Answer saved; no linked work.” Return to origin.

One: “View 1 affected task” opens filtered Work; a named task link can open detail.

Several: show every affected task, including those still blocked.

Unknown impact is labeled unknown; never converted into zero.

E2 · T3–T6 · Same task / current-action region

Waiting and recovery

Worker offline: queued, waiting for worker; cancel available.

Queue conflict: authorization recorded; reconcile before dispatch.

Input needed: answer → review continuation scope → authorize.

Cancel uncertain: reconcile; do not report stopped.

Failed: inspect boundary; new attempt only after safe retry authorization.

Preserve task, mapping, attempts and source context.

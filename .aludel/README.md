# Aludel base layer

The base layer every Aludel layer starts from. Each installed layer instance is its own repository, forked from this repository's `main` branch or from a template branch built on it (`markdown`, `pages`). The instance's `main` branch is what Aludel builds and serves; work arrives as branches and is merged after review.

See `docs/layer-contract.md` for the contract between a layer and its host.
